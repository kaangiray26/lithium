Lithium

Compatibility tool for macOS based on Valve's Proton and additional components

What is it

Lithium runs unmodified Windows games on Apple Silicon Macs, built entirely from open components — WineHQ Wine, Valve's DXVK, and Khronos's MoltenVK — rather than Apple's private Game Porting Toolkit engine.

No emulation of Apple's private tooling, no black box: Wine loads and runs the game's real x86_64 code under Rosetta 2, DXVK translates its DirectX calls to Vulkan, and MoltenVK translates Vulkan to Metal.

Install

As a standalone tool:

uv tool install lithium-cli

Then build the stack (Wine, DXVK, MoltenVK) and you're ready to go:

lithium build
lithium doctor

Quickstart

lithium prefix create <name>
lithium install <name> /path/to/setup.exe
lithium run <name> "prefixes/<name>/drive_c/Games/<game>/Game.exe"

Approach

Windows game (x86_64 PE, DirectX)
↓
Wine — Win32/PE loader + API emulation (x86_64, under Rosetta 2)
↓
DXVK — DirectX 9/10/11 → Vulkan
↓
MoltenVK — Vulkan → Metal
↓
Metal (GPU)

Status

Milestone: Hollow Knight: Silksong runs and is playable end to end — Wine, DXVK, and MoltenVK combine to run a real commercial game on Apple Silicon without Apple's private Game Porting Toolkit engine.
